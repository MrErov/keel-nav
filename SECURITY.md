# Security Policy

## Supported Versions
Keel Nav is currently in Beta (v0.4.x).

## Reporting a Vulnerability
Since Keel Nav is a Markdown-based methodology (not executable code), the primary security risk is prompt injection when using the meta-skills with an AI agent. 
If you find a flaw in the prompt engineering that allows an agent to bypass a phase or write un-audited code, please open an issue with the label `security`.
